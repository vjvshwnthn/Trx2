# TraxnFirstMktg website

Static five-page site, ready for GitHub and Netlify or Vercel.

## Preview
Open `index.html` in a browser. Navigation and animations work without a build step.

## Deploy
- **Netlify**: Import the GitHub repository as a new site. Build command: leave blank. Publish directory: `.`
- **Vercel**: Import the GitHub repository. Framework preset: Other. No build command.
- **GitHub Pages**: Settings → Pages → Deploy from branch → main / root.

## Files
- `index.html` — homepage with animated three-card GTM deck, founder-sprint process and FAQ
- `products.html` — three capability offerings
- `about.html`, `resources.html`, `blog.html` — other site pages
- `styles.css` — shared visual design
- `gears.js` — interlocking gear animation

## Before publishing
- Replace `hello@example.com` contact placeholder.
- Resources and blog entries are planned placeholders.
- Confirm that any named third-party tools accurately reflect your delivered stack.
- Review copy, accessibility and mobile presentation.

The homepage now has three rotating interlocking gears with a sequential color spotlight and progressively revealed capability pills.
